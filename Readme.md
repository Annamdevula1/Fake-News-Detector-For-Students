# Fake News Detector for Students

## Problem Statement
Misinformation spreads quickly through online news and social media, making it hard for students to identify reliable information.

## Solution
This project uses Machine Learning to classify news articles as Real or Fake and provides a short summary.

## Features
- Fake News Detection
- News Summary
- Trustworthiness Tips
- Streamlit Interface

## Technologies
- Python
- Streamlit
- Scikit-Learn
- Pandas

## Run Project

pip install -r requirements.txt

streamlit run app.py
