📌 Project Overview

The Fake News Detector for Students is a machine learning project that helps identify whether a news article is Fake or Real. It is designed to improve digital literacy by enabling students to verify online news before believing or sharing it.

🎯 Objective

To classify news articles as Fake or Real using Natural Language Processing (NLP) and Machine Learning techniques.

🚀 Features

- Detects fake and real news articles.
- User-friendly interface.
- Fast and accurate predictions.
- Designed for educational purposes.

- Python
- Google Colab
- Scikit-learn
- Pandas
- NumPy
- Streamlit

🤖 Machine Learning Model

- TF-IDF Vectorizer
- Passive Aggressive Classifier

📊 Dataset

- Fake and Real News Dataset

The model predicts whether the given news article is:

- ✅ Real News
- ❌ Fake News
